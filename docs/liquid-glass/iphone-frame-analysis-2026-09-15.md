顶部和底部控件分别检查。量化为解码后 RGB 通道值，不是线性光亮度。固定 ROI，坐标为左上闭、右下开：顶部胶囊空白区 [710,179,760,229]，右侧圆按钮空白区 [1035,162,1075,185]，邻近背景 [860,330,920,390]，标题下方阴影 [690,303,760,323]，底部删除图标 [975,2325,1054,2430]。图标区域误差包含模糊、淡入与小幅移动，不能当成模糊核宽度。

下面的接近稳定时间，定义为此后所有剩余帧的 ROI 相对片尾帧平均绝对通道差 MAE 均≤3/255。这是可复算的本次观察标准，不是苹果性能承诺，也不证明无限时间稳态。

## 实测观察

### 白底

顶部胶囊空白区的三通道均值轨迹：

| 帧 | PTS ms | 均值 /255 |
|---:|---:|---:|
| 0 | 0.0 | 244.8 |
| 6 | 100.0 | 250.5 |
| 7 | 116.7 | 251.4 |
| 8 | 133.3 | 190.7 |
| 9 | 158.3 | 197.1 |
| 12 | 208.3 | 214.1 |
| 16 | 275.0 | 229.4 |
| 22 | 375.0 | 241.3 |
| 30 | 508.3 | 248.2 |
| 48 | 808.3 | 251.4 |

116.7→133.3 ms 两个相邻显示帧间，胶囊空白区下降约 60.7；旁边背景维持约 247.2–247.3。三个顶部控件都出现短暂暗化，随后背板恢复浅色、前景变深。不是整张背景变暗，也不只是文字淡入。

片尾顶部边界附近可见：内部约 [250,251,253]，细边约 [254,254,255]，紧邻下沿外侧约 [232,233,235]，远处背景约 [246,247,249]。白底的轮廓分离依靠细亮边与轮廓外的柔阴影，并不是最终保留深灰实心背板。柔阴影在视频中延伸到轮廓外数十像素，不能把这些像素数直接套到 Windows 的 39 像素胶囊。

底部的主要过程不同：形体建立、图标由弥散模糊变为清楚，没有与顶部相同强度的突然灰化。底部空白区约 258 ms 接近片尾颜色，删除图标区域约 475 ms 才满足 MAE 标准。因此不能用一条全局 opacity 曲线概括所有层。

### 绿底

文件名不代表每个控件都是绿底：顶部在绿色与白色大字上；底部实际在白底与深色文字上。顶部保留绿色与背景笔画的折射、平滑，不是整体洗成白色。

顶部右侧圆按钮避开背景笔画的空白区：116.7 ms 为 [0,187,66]，133.3 ms 为 [0,157,43]，片尾为 [0,187,64]；外侧背景约 [9,183,86]。也存在较弱的暗化—恢复过程。顶部并非在任何背景笔画下都完全无干扰，不夸大素材可读性。

### 黑底

顶部胶囊空白区从约 1/255 逐步抬到约 24/255，文字由暗转亮，没有白底中同强度的反向灰化。顶部约 125 ms 已接近片尾；底部图标更晚建立清晰轮廓。

| 片段 | 顶部胶囊空白区接近片尾 | 底部删除图标 ROI 接近片尾 |
|---|---:|---:|
| 白 | 558 ms | 475 ms |
| 绿 | 392 ms | 442 ms |
| 黑 | 125 ms | 317 ms |

未遮挡场景固定 ROI [450,600,740,1050] 相对片尾的最大 MAE，白/绿/黑仅约 0.061/0.204/0.329。主要变化在控件入场，而不是大幅场景切换。

重要边界：三个片段是不同背景上的控件唤出，不是同一个已经显示的控件连续跨越白、绿、黑背景的阶跃测试。无法唯一分离苹果内部的适配、交叉淡化、图标动画及系统调度。可以拟合可见输出，不应声称复原了苹果私有着色器。白、绿顶部圆按钮恢复段的描述性单指数拟合尺度约 140/153 ms，仅供本项目调参起点，不是苹果内参。尤其不能把 133 ms 写成固定闪灰定时器。

## 当前代码的具体差距

检查基线文件：`experiments/glass-live/src/liquid.hlsl`、`liquid.rs`、`voice_window.rs`。

1. `liquid_adapt_ps` 已有 85 ms 场景亮度平滑，但 1×1 历史主要驱动黑/白字选择与细节量。`transmit(scene,dark)` 按主题使用固定系数，缺少完整的材质对比度目标、响应与恢复状态。不是完全没有适配，也不是没有真实折射。
2. 首次历史样本 `first ? 1 : ...` 直接到目标；`time/0.24` 主要驱动形体显现，不能代替独立材质收敛。`text_mask` 是清晰字形乘显现权重，没有单独的前景由模糊到清晰通道。
3. 会话创建时开始计时，首次取得有效桌面帧之后使用累计时间渲染。如果首帧就绪延迟，入场时间会在控件真正显示前消耗。源码证明存在这种风险，本次没有测量用户机器是否实际发生。
4. 白底低细节条件阴影幅度只有 `.10 + .16*complexity`，宽度尺度 `h*.052`，39 px 高时约 2.03 px。纯白输入基础透射编码后约 [249.5,250.9,252.4]，与白色外界很接近。仅调小 85 ms 不会产生所需的空间层次。
5. 更重要的是画布约束：当前生产 HWND、呈现表面和逻辑胶囊都是 `108×26 DIP`，并设置同尺寸圆角 Region。形体垂直余量仅约 `.045h`。现有 26 px padding 属于采样 ROI，并不是呈现窗口外侧的阴影留边。只增加 shadow 参数、不解耦画布和裁切，无法画出素材中的宽柔阴影。

## 下一版实现与验收约束

- [ ] 解耦逻辑胶囊、输出画布、采样 ROI。给柔阴影真实输出空间，但不扩大视觉主体、点击或拖拽区域；处理 DPI、屏幕边界与裁切，不能重现矩形脏边。
- [ ] 分离形变、材质适配、前景呈现三条时间轴；视觉入场从首个可用背景进入呈现时起算，不以初始化成本起算、不延迟录音。
- [ ] 根据局部亮度/色彩/细节、边界与内容对比风险共同决定透射、细边、外阴影、局部前景保护。白底补层次，绿底留色与折射，黑底建立暗基底和亮前景；不能统一刷灰。
- [ ] 连续收敛和稳定保持；背景变化时跟踪，稳定后不能不停呼吸/抖动。140–150 ms 可作首轮工程拟合起点，须明确是项目参数，不是苹果内参。不要故意复制早期不可读或固定灰闪。
- [ ] 原始彩色波形 `#43DED2 → #648DFF` 20 级颜色与真实音量驱动不变。通过局部背景支撑增强对比，不再把波形转成黑白。前景动效不得让实际语音反馈长时间模糊。
- [ ] 保存 0/50/100/133/200/300/400/600 ms 的真实生产 HLSL 合成输出，而非只比较 2 秒后的静态图。覆盖白、黑、绿与细字背景，比较同输入/同时间的基线和候选。
- [ ] 补充白↔黑、白↔绿工程阶跃测试，同时明确这不是原录屏里的测试。测试场景稳定、快速反向切换与首次采样等待，不能用空源或重复帧假装稳定。
- [ ] 保留标签与旧光学参考；新材质有意改变输出，不能强称新旧全部像素相同。保持波形颜色核、预乘 alpha、实际语音状态、快捷键、粘贴、失败回退、禁用/隐藏释放等独立契约。

这些条目目前是基于实际逐帧分析的改造要求，尚未标为已实现或本机已验收。当前版本与运行环境不作隐式替换。
